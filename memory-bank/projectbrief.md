# Project Brief: Finora Service

## Overview
Finora Service is the backend system for the Finora platform, designed for Research Analysts. It is responsible for managing core business logic and integrations, following a hexagonal (ports and adapters) architecture.

## Core Requirements & Goals
- Serve as the backend for the Finora platform.
- Implement and manage a robust Role-Based Access Control (RBAC) system using Supabase.
- Enable uploading and management of various contact lists.
- Provide comprehensive management for the Sales module.
- Provide comprehensive management for the Advisory module.
- Ensure scalability, maintainability, and security through clean architecture and best practices.

## Scope
- Backend only (no frontend/UI).
- Integrates with Supabase for authentication and RBAC.
- Modular design to support future feature expansion.
- Focus on reliability and clear separation of concerns.

## Out of Scope
- Frontend development.
- Non-research-analyst user flows.
- Non-core modules not listed above.
